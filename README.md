Esses scripts são parte dos estudos que venho realizando através do curso maratona Java, ministrado pelo Willian Suane, vulgo DevDojo, que está disponível em seu canal no Youtube.
São linhas de código que buscam exemplificar na práticas os conceitos de programação, além de entender as particularidades da linguagem Java em si.

Eu venho utilizando todo esse material para estudo e consulta, até o momento ainda não assisti todas as aulas do curso,
é um processo continuo e demorado, pois assisto as aulas e vou copiando os exemplos que o Willian passa, além de muitas vezes
eu mesmo deixar meus próprios comentários no código para entender em uma possível consulta no futuro.
Ou seja, é um estudo buscando foco total nos conceitos e revisões periódicas visando aperfeiçoar a habilidade de programar. 

No pacote "introducao" que  encontra-se os conceitos básicos da linguagem (Tipos Primitivos, Operadores Lógicos, Estruturas Condicionais, Estruturas de
Repetição e Arrays).

Já no pacote "javacore" teremos uma série de outros pacotes, onde cada um desses pacotes terão mais outros dois pacotes denominados "dominio", onde são guardadas as classes
e "teste" onde são as classes de exucução/testes das aulas. No geral, todos esses conceitos estão envolvendo o assunto de Programação Orientada a Objetos, o que é a espinha dorsal
do curso e provavelmente do mundo contemporâneo da programação em todas as linguagens do mercado baseado nesse paradigma.
